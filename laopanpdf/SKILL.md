# 老潘申报表网页转完整 PDF

使用 `scripts/laopanpdf.py` 从每次提供的 HTML 重新抽取数据，不得复用上一份申报表的公司、人员、证件号码、日期或项目数据。

## 执行

1. 确认输入是完整保存的 `cerDeclarePrint.html` 或结构相同的网页。若只有已被截断的 PDF，请用户补充源 HTML。
2. 在当前工作区运行：

```bash
python3 "{skill_path}/scripts/laopanpdf.py" "<输入网页.html>" -o "<当前工作区>/<网页名>_完整打印版.pdf" --qa-dir "<当前工作区>/laopanpdf-qa"
```

3. 若输出目录已存在同名 PDF，允许覆盖该生成稿；不要覆盖用户原始网页或原始 PDF。
4. 检查命令返回的 `contact_sheet`，逐页查看联系表，并重点检查第 3 页合并单元格、人员与项目表，以及末页意见栏。图片超过 3 MB 时先压缩副本再查看。
5. 抽取成品 PDF 文字，核对卷宗号、公司名、备案日期、证件号码、各表行数和汇总文字。发现缺失、重叠、裁切或跨页断表时，先修复再交付。
6. 交付生成的 PDF 文件链接，并说明页数和已完成的检查。

## 固定版式

- A4 纵向，7 个标准栏目各自起页；内容增加时按整行自动续页，不截断单元格。
- 表格宽度不得超出左右各 15 mm 的可打印区域，长文字和号码自动换行。
- 封面、法定代表人承诺、基本情况、出资情况、估价师情况、代表性项目、机构简介与意见栏均从 HTML 动态抽取。
- 第 3～6 页必须按 HTML 实际网格重建，保留各表不同的列数、相对列宽、行高和合并单元格；禁止把栏目硬套进固定列数或固定字段顺序。
- 清除网页用于定位的首尾空白单元格，保留有意义的合并单元格；备案取得时间与备案日期必须同时保留。
- 末页机构申报意见左对齐并在整栏内垂直居中。
- 三个意见栏的盖章和日期均位于右下方，盖章在上、日期在下；年月日之间保留手写空间。

## 异常处理

- 解析脚本提示缺栏目或字段时，检查 HTML 是否完整、是否来自同一网站；不得静默省略内容。
- 网站结构发生变化时，按实际 HTML 调整解析脚本并重新回归测试，不得硬编码当前样例数据。
- 缺少 Python 依赖时，使用 `python3 -m pip install -r "{skill_path}/requirements.txt"` 安装。
- 字体会自动适配 macOS、Windows、Linux；自动检测失败时，用 `--font-regular` 和 `--font-bold` 指定可用中文 TrueType 字体，不得在未生成 PDF 时声称成功。
